# 四川师范大学 APA 毕业论文格式

Use this skill whenever preparing a homework paper, course paper, graduation thesis draft, or DOCX that must follow the user's Sichuan Normal University APA-style format. Apply the format proactively; do not switch to Chinese legal-style headings such as "一、二、三、".

## Workflow

1. Collect or infer the required metadata: title, major, author details if provided, topic requirements, source text, citations, and references.
2. Draft or reorganize the paper in this order as applicable: title, major, Chinese abstract and Chinese keywords if the document has Chinese content, English abstract and English keywords if the document has English content, table of contents, body, references, appendices if any.
3. Use only Arabic hierarchical heading numbers: `1`, `1.1`, `1.1.1`. Limit headings to three levels.
4. Generate the table of contents through the document editor's built-in TOC mechanism from heading styles; never type the TOC manually.
5. Ensure TOC page numbers match the final document after pagination.
6. Format citations and references consistently with the rules below.
7. For DOCX output, use real Word styles, paragraph settings, page-number sections, and automatic fields where possible.

## Front Matter

Apply these styles:

- Title: Songti, "小二", centered.
- Major line such as `XX专业`: Heiti, "小四", centered.
- Chinese abstract heading `摘要`: Heiti, "小四", bold, centered.
- Chinese abstract body: Songti, "小四", first-line indent 2 Chinese characters, fixed line spacing 20 pt.
- Chinese keywords label `关键词`: Heiti, "小四", bold, first-line indent 2 Chinese characters. Put one space after `关键词`; include 3-5 keywords separated by spaces.
- English abstract heading `Abstract`: Times New Roman, "小四", bold, centered.
- English abstract body: Times New Roman, "小四", no first-line indent, fixed line spacing 20 pt. If both Chinese and English abstracts are present, their meaning must match.
- English keyword label: only `Keyword:` is Times New Roman, "小四", bold, italic, with first-line indent 1.27 cm.
- English keyword content: the words after `Keyword:` are Times New Roman, "小四", not bold, not italic, no extra indent beyond the paragraph setting, fixed line spacing 20 pt. Use 3-5 lowercase keywords separated by English commas.

Use `Keyword` exactly unless the user explicitly asks for `Keywords`.
Do not add an English abstract or English keywords when the supplied document only has Chinese content and the user has not requested bilingual expansion. Likewise, do not add a Chinese abstract or Chinese keywords when the supplied document only has English content and the user has not requested bilingual expansion.

## Table Of Contents And Page Numbers

- The table of contents must be inserted/generated by the system from heading styles, not typed manually.
- The TOC page itself has no visible page number.
- If both Chinese and English abstracts exist, their page numbering styles must be different: use roman numerals for the Chinese abstract section and Arabic numerals for the English abstract section unless the assignment gives stricter instructions. The body should also use Arabic numerals and may restart at page 1 if the paper template requires it.
- Confirm the final TOC entries correspond to actual heading text and page numbers.
- In TOC display, first-level headings should show a trailing dot, for example `1.`.
- After inserting the generated TOC, manual adjustment of font and line spacing is allowed for appearance only; do not break field linkage if a DOCX is expected.

## Headings

Use only these heading levels:

- Level 1: number format `1`, `2`, `3`; Heiti, size "三号", not bold. Paragraph has no indent, 17 pt before, 16 pt after, fixed line spacing 20 pt.
- Level 2: number format `1.1`, `1.2`; Heiti, size "四号", not bold. Paragraph has no indent, 13 pt before, 13 pt after, fixed line spacing 20 pt.
- Level 3: number format `1.1.1`, `1.1.2`; Heiti, size "小四", not bold. Paragraph has no indent, 13 pt before, 13 pt after, fixed line spacing 20 pt.

All headings must be black, including built-in Word heading styles that otherwise default to blue. Do not use numbering forms such as `一、`, `二、`, `(一)`, or more than three heading levels. Do not put a trailing dot at the end of the actual heading number except where required by the generated TOC display. Do not insert page breaks between body headings or force each body heading to start on a new page.

## Body Text And Tables

- Body text: Songti, "小四", fixed line spacing 20 pt.
- Use first-line indent 2 Chinese characters for ordinary Chinese body paragraphs unless a specific paragraph type requires no indent.
- Keep table numbers consistent with the text, such as `表1`, `表2`, or the requested numbering style.
- Introduce every table in the body before or near the table.
- Make table titles, notes, and references consistent with the paper language and assignment requirements.

## In-Text Citations

Use APA-like author-date citations:

- One author parenthetical: `(Perloff, 2014)`.
- One author narrative: `Perloff (2014)`.
- Two authors parenthetical: `(Meier & Gray, 2014)`.
- Two authors narrative in Chinese text: `Meier 和 Gray (2014)`.
- Three or more authors parenthetical: `(Grabe et al., 2008)`.
- Three or more authors narrative in Chinese text: `Grabe 等 (2008)`.
- When citing multiple works in one parenthesis, separate works with semicolons and sort alphabetically, for example `(Grabe et al., 2008; Meier & Gray, 2014; Perloff, 2014)`.

## References

Start references on a new page. Use the heading `参考文献`; the four-character heading must be centered. Format entries as:

`Author. (Year). Title. Journal, Volume(Issue), pages.`

Rules:

- Sort references alphabetically by authors' surnames.
- If authors are identical, sort by publication year.
- If authors and year are identical, sort by title and add `a`, `b`, `c` after the year.
- Write all reference entries in English.
- For Chinese sources, include the source's official English bibliographic information first, then place the Chinese original information in square brackets after it. Do not invent or freely translate English information; use the original source's English metadata when available.
- Use English half-width punctuation in Chinese-source bibliographic records.
- Add one space after English commas, periods, and colons.
- End each bibliographic component with a period where appropriate.
- Apply hanging indent to each reference entry.
- Ensure every entry has an italicized part, usually the journal name and volume, book title, conference title, or similar source container.
- Set references in Times New Roman unless Chinese characters inside brackets require an appropriate Chinese font.

## Quality Checks

Before finalizing:

- Verify the document uses Arabic hierarchical headings only.
- Verify all headings are black and body headings do not create unnecessary page breaks.
- Verify title, major, abstracts, keywords, headings, body, TOC, and references follow the specified fonts, sizes, indentation, and spacing.
- Verify Chinese and English abstracts match in meaning when both are present.
- Verify keyword counts are 3-5 for each present language.
- Verify the TOC is generated from heading styles and has no visible page number.
- Verify page-number sections use the required roman/Arabic distinction.
- Verify every in-text citation has a matching reference entry and every reference is cited, unless the user provided a bibliography-only requirement.
- Verify references start on a separate page, the `参考文献` heading is centered, and entries are sorted with hanging indent.
